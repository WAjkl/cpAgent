# ISSUE-009 工具结果截断导致 LLM 误判"型号不存在"

- **日期**：2026-08-13
- **状态**：✅已解决
- **影响**：高（对比场景假阴性：库里有 RTX 5060/RX 9070，LLM 却答"库中无此型号"）

## 现象

用户问"RTX 5060 和 RX 9070 哪个好"，LLM 查询 GPU 后回答"数据库中没有 RTX 5060 这款显卡"。但 `hardware_db.json` 里明明有 RTX 5060（live ¥2365）和 RX 9070（live ¥4392）。

## 根因

两层截断叠加：
1. `query_hardware_db` 工具默认 `limit=10`，按性能分排序后 RTX 5060（低端）排不进前 10
2. `_summarize` 摘要只展示前 8 条

LLM 只能看到高端卡（RTX 5090/4090/5080...），误以为"库中没有该型号"，进而**正确执行幻觉铁律**（没编造价格）但**事实判断错误**（说无此型号）。

## 解决方案

1. 工具默认 `limit` 10 → 30（全部返回）
2. `_summarize` 展示全部结果（最多 20 条）
3. 验证：对比场景一次工具调用即命中两卡，回答正确

## 教训

给 LLM 的工具返回**不能静默截断**关键数据；截断造成的"假阴性"比"假阳性"更难发现（LLM 会基于残缺数据给出自信的错误结论）。宁可多花 token 展示全量，也不要截断导致误判。
