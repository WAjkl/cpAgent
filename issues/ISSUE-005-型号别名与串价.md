# ISSUE-005 RTX 5060 Ti 别名匹配 + 模糊匹配串价风险

- **日期**：2026-08-13
- **状态**：✅已解决
- **影响**：高（若不处理会串价：RTX 5070 Ti 拿到 RTX 5070 的价格）

## 现象

- `RTX 5060 Ti 8GB`（库型号）与实测 `RTX 5060 Ti`（源型号）不一致，精确匹配失败 → 该型号退化为估算
- 若改用 `startswith` 模糊匹配：`"RTX 5070 Ti".startswith("RTX 5070")` 为 True → **RTX 5070 Ti 会错误匹配到 RTX 5070 的 $635.99**，串价风险

## 根因

型号命名粒度不一致（源站 8GB 版就叫 "RTX 5060 Ti"，库为了区分显存版本加了 "8GB"）；模糊匹配方向错误。

## 解决方案

1. 精确匹配优先（`m == model_norm`）
2. 显式别名表兜底（不允许通配）：

```python
GPU_ALIAS = {"RTX 5060 Ti": "RTX 5060 Ti 8GB"}
# 匹配条件：精确相等 或 GPU_ALIAS.get(m) == model_norm
```

3. 构建后自检：无 null 价格、无重复型号（已加进构建脚本执行后的校验步骤）

## 教训

型号对齐用**精确匹配 + 显式别名表**，永远不要 startswith 模糊匹配（前缀包含关系必然串价）；数据自检（null/重复）应在构建脚本内闭环。
